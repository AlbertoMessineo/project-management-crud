# Project Management App

Un'applicazione di gestione progetti sviluppata con Angular (frontend) e Node.js con Firebase (backend).

## Prerequisiti

Prima di avviare il progetto, assicurati di avere installati:
- Node.js (>= 18)
- Angular CLI: `npm install -g @angular/cli`
- Firebase CLI: `npm install -g firebase-tools`

## Installazione

Clona il repository ed entra nella cartella del progetto:
```sh
git clone https://github.com/tuo-repo.git
cd tuo-repo

cd frontend
npm install
cd ../backend
npm install

Configurazione Backend
Il backend è costruito con Node.js, Express e Firebase.
